课件超级工作台安装说明 · v1.0

只支持 Mac 电脑
2026 年 11 月

需要提前准备

一台 MacIntel 或 Apple 芯片都可以。工作台和你的课程资料都在这台电脑上。
Python 3.11+Mac 自带的版本太旧。安装脚本会自动检查，缺了会打开下载页，照提示装一下就行。
DeepSeek API key生成教案和逐页提示词要用。到 platform.deepseek.com 注册创建，按用量自付，一节课通常几分钱到几毛钱。
Google Chrome自动操作 Gemini Notebook 生成课件要用，需要一个能正常使用 Gemini Notebook 的 Google 账号。
LibreOffice可选检查 PPTX 课件、生成逐页预览要用。libreoffice.org 免费下载。
Canva 账号可选把图片课件拆成可编辑图层要用。需要你自己的 Canva 开发者应用和 AI 额度；这是 Canva 的预览功能，不保证每个账号都能用。

1放好文件夹

  1. 双击压缩包解压，得到「课件超级工作台」文件夹。
  2. 把整个文件夹拖到文稿里（不要留在「下载」里）。
  3. 装好以后不要再移动或改名。移动了就再双击一次「安装依赖」。

2双击「安装依赖.command」

  1. 会打开一个黑色的终端窗口，自动检查电脑并安装，第一次约 5–20 分钟。
  2. 缺 Python 会打开下载页：下载 macOS universal2 installer，装好再双击一次。
  3. 最后会请你粘贴 DeepSeek key（屏幕不显示，粘好回车）。看到「安装完成」就好了。

3双击「启动工作台.command」

  1. 浏览器会自动打开 127.0.0.1:8792，这就是工作台。
  2. 使用期间别关那个终端窗口；用完直接关掉。
  3. 以后每次使用，只需要这一步。

4做第一节课

  1. 左上角「新建课程」，填课名和学科。
  2. 选「全自动」→ 放入教材页（照片、PDF、Word 都行）→ 选课时和页数 →「发车」。
  3. 第一次跑到 Notebook 时会弹出一个单独的 Chrome 窗口，在里面登录 Google 一次即可；密码不经过工作台。

第一次双击时被系统拦住？

提示「无法打开」或「无法验证开发者」是 Mac 对网上下载文件的正常保护。打开系统设置 → 隐私与安全性，往下找到这个文件的提示，点仍要打开，输入电脑密码确认。每个 .command 文件只需要这样放行一次。较早的 macOS 也可以按住 control 键点文件，选「打开」。

常见问题

安装卡住或报错？
脚本先用国内镜像，失败会自动换官方源再试。还不行就检查网络，再双击一次。
想换 DeepSeek key？
双击「设置DeepSeek密钥.command」，再重新启动工作台。
提示端口被占用？
先关掉之前的工作台窗口，或重启电脑后再启动。
Notebook 那一步停住了？
看看弹出的 Chrome 窗口是否要登录或确认；处理好后在工作台点「继续」。

资料和隐私

  • 课程和文件都保存在本文件夹的 data/local_workbench 里，不会上传给作者。备份时复制这个文件夹即可。
  • 生成教案时，教材和教案文字会发给 DeepSeek；课件生成会用到你的 Google 和 Canva 账号。请不要放入学生的姓名、照片等个人信息。
  • 不要把 data 文件夹或 config.local.json（里面有你的 key）发给别人。
