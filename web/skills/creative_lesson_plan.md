# 内置 Skill · 创意详案（教材原文 + CASE 创意任务）

改编自教师提供的「单元教案详案化（lesson-plan-detail-expander）」技能，只保留与起草、扩写教案文字有关的规范。

## 一句话定位

把「描述性简案」变成「可执行的课堂脚本」：教材原文进教案、每个环节能照着上课、创意任务有真实情境与课标依据、评价证据可收集。判断标准：一位没参与备课的老师拿着这份教案，能不能不看教材、不猜教师意图，直接照着上一节课。

## 三条底线

1. **教材原文只从【教材文字】里抄**。教案底稿里的描述、练习、课件改写版都不能冒充教材原文。教材文字里没有的句子，一律标注「教师补充例句（非教材原文）」。
2. **发现底稿与教材原文冲突就纠正**（人物、情节、例句出处、概念边界），并在该课时写一段「文本核对提示（教师用）」说明改了什么、依据哪句原文。不改写教材原文本身；原文里概念归类不严谨的，原样保留并作为思辨素材。
3. **不编造**：不编人数、正确率、前测分数等数字；课标查不到条目号就写章节名，不编编号；学科事实与语言点写「建议教师核实」。

## 教材语篇全文

在本课时教学过程之前写一块「【教材语篇全文 · 第 N 课时】」：

- 逐句录入本课时用到的教材语篇（主题词、歌曲/歌谣、对话、故事、Project 步骤），歌曲、对话逐句分行，不改写。
- 对话原文没有角色标记时，按语义标 Teacher / S1…，并注明「角色标注依语义划分，教师可按教材人物名调整，句子不改动」。
- 「归纳语料」只放教材原句；自编句另起一行，标「教师补充例句（非教材原文，仅供操练）」。
- 最后写「语篇研读与文本核对提示（教师用）」：主题与内容、传递的意义与价值、文体结构与语言特点，再列出与底稿冲突之处。

## 每个教学环节写满八个字段

以「【时长｜活动类型】」开头，例如「【8 min｜学习理解·感知与注意】」，各环节时长相加等于本课时总时长。

1. 时长与活动观定位（学习理解 / 应用实践 / 迁移创新）。
2. 教师原话「T:」：写真正会在教室里说出口的句子（英语课写英文），不写「教师引导学生……」。驱动问题要板书、全课不擦。
3. 学生预期「S:」：2–3 种真实回答，包含不完整的回答。
4. 编号步骤 ①②③：每步带分钟数和产出，步骤之间要递进。
5. 【文本落地】：这一步用教材哪一句原文，逐句铺进对应步骤（教到哪句就出现哪句），或写明「此处不用教材、用教师补充例句」。
6. 【分层】：基础层 / 进阶层 / 挑战层各一个可做的动作。
7. 【易错预判】：预测一个具体的错（发音重音、搭配、易混词），写清教师怎么不公开纠错地处理。
8. 【课后衔接】：本环节产出如何进入下一课时或单元大任务。

每个环节末尾可加「环节小结 · 承上启下」，用教材原句或一句小 chant 收束并过渡。

### 目标与评价

- 目标写三条可观测的行为，不用「了解、掌握、培养」这类不可测动词；附「素养锚点」和「课标依据」（引用《义务教育课程标准（2022年版）》对应学科的章节名，英语可写「四、课程内容」「五、学业质量」「六、课程实施（一）教学建议·英语学习活动观」等）。
- 评价至少包含：观察点（能看见的行为证据）、★/★★/★★★ 三档量表（活动前公开，敢开口也给星）、评价主体（自评/互评/师评/真实读者各做什么）、一句教师真会说的可执行反馈；禁止「多鼓励」「加强巩固」。

## ★ 创意任务（每课时一个，嵌入迁移创新环节，不另加时间）

把原来泛泛的「头脑风暴/讨论」替换成一个 CASE 情境链，标题写「★ 创意任务 / CASE 情境链（嵌入迁移创新环节 N min，不另加课时）」：

- **C 联结生活**：情境素材来自学生真实生活或本校现场（本班物品、教室实拍、自己带来的旧物），注明「不用网图、不摆拍」，给出教师开场原话。
- **A 驱动问题**：一个能拆成子任务、逼出判断而不是复述的问题，板书。
- **S 探究序列**：2–4 个递进子任务，每个带分钟数、分组角色、必须使用的句式、产出。
- **E 情境回收与迁移**：课末回到驱动问题作答，给出真实受众与真实后续（值日生复查、一周后同角度拍照、放图书角）。

另写三小段：

- 【材料与安全】逐项列器材；涉及实物操作写安全边界（只用干燥废弃物、剔除尖锐物、活动后洗手、过敏学生改任记录员、工具由教师操作）。
- 【跨学科融合】以本学科为主干，逐科写清「它提供了什么、去掉它任务哪里做不成」，给学生一句能说出口的总结句。
- 【分层】【量表】【证据留存】同上文规范，写清本环节产出如何进入下一课时。

## 写完自查（不要把清单输出到教案里）

- 每个环节都能找到至少一句教材原文，或明确写了「此处用教师补充例句」。
- 教师话术是能直接说出口的句子。
- 评价证据是能看见的行为。
- 创意任务的情境能在本校/本班找到实物或照片，不是虚构故事。
- 没有编造的数字；需要核实的事实已标注「建议教师核实」。
- 各环节时长相加等于本课时总时长，创意任务不额外占时间。

## 篇幅

只写指定的一个课时，全文控制在 6000 字以内：语篇全文与教学过程写细，其他栏目从简。若另有学校模板，栏目顺序以模板为准，以上内容填进模板对应栏目。
